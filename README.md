## Project Description

This project is a React web application built with **Vite** and **TypeScript**, providing a fast and efficient development experience. It includes modern React features such as hooks and component-based architecture. The project uses **Tailwind CSS** for styling and is configured for easy expansion and scalability.

## Installation Instructions

Follow these steps to get the project running locally:

1. **Clone the repository to your local machine:**

   ```bash
   git clone https://github.com/rana-m-h/super-fitness.git
   ```

2. **Navigate into the project directory**:

   ```bash
   cd super-fitness
   ```

3. **Install dependencies** using yarn:

   ```bash
   yarn install
   ```

   This will install all the required packages for the project.

## Usage Instructions

To run the project locally, follow these steps:

1. **Start the development server**:

   ```bash
   yarn dev
   ```

2. **Access the app**:
   Open your browser and visit [http://localhost:5173](http://localhost:5173) to view the project running locally.

## Features

The project includes the following features:

- **Cart Functionality**: Add to cart, view cart, and checkout options integrated with **React Query**.
- **Responsive Design**: Built using **Tailwind CSS** to ensure the website is mobile-friendly.
- **Image Carousel**: **Embla Carousel** for a smooth image-sliding experience.
- **Forms and Validation**: **React Hook Form** and **Zod** for form management and validation.
- **Multi-Language Support**: Translations and localization with **UseIntl**.
- **UI Components**: Styled using **ShadCN** for a modern look and feel.
